# Vocab Daily - 每日单词

一个专为手机设计的英语单词学习工具，每天500词，主题化学习，认识的词自动过滤。

## 功能特点

- **主题化词库**：超市、厨房、军事、无人机等20+主题
- **每日500词**：自动组卷，认识的移除，不认识的明天继续
- **美式发音**：内置语音朗读
- **当天可撤销**：误标记的词可以一键恢复
- **主题筛选**：只学你感兴趣的主题
- **AI生成向导**：输入任意主题，自动生成词库
- **数据备份**：一键导出/导入，换设备不丢进度
- **PWA支持**：添加到手机桌面，像APP一样使用

## 如何使用

1. 用浏览器打开 `index.html`
2. 添加到手机主屏幕（Chrome/Safari 菜单 → 添加到主屏幕）
3. 每天打开刷500个单词

## 自定义词库

在应用内进入「主题生成」页面：
1. 输入你想要的主题（如"航空发动机"）
2. 复制生成的提示词，粘贴到任意AI聊天工具
3. 把AI返回的结果粘贴回应用
4. 确认导入即可

## 数据存储

所有数据保存在浏览器本地 IndexedDB 中。建议定期在「设置」页面导出备份。
