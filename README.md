# Vocab Daily - 每日单词

英语单词每日学习工具，每天 500 词，主题化学习，认识的词自动过滤。目前主用场景是**电脑本地**。

## 功能特点

- **主题化词库**：超市、厨房、军事、无人机等 22 个主题，597 个内置单词
- **每日500词**：自动组卷，认识的移除，不认识的第二天优先复习
- **美式发音**：本地音频文件（不依赖网络），失败时回退系统语音
- **当天可撤销**：误标记的词可以一键恢复，刷新页面后仍然可以
- **主题筛选**：只学你感兴趣的主题
- **AI生成向导**：输入任意主题，自动生成词库（自动去重）
- **数据备份**：一键导出/导入；首页在超过 7 天没备份时提醒
- **键盘操作**：`→` 认识、`←` 不认识、`空格` 重听

## 如何使用（电脑）

1. 双击 `start-server.bat`
2. 2 秒后浏览器自动打开 `http://localhost:8080/`，开始学习
3. 学完直接关掉黑窗口即可

⚠️ 学习进度保存在浏览器的本地数据库里，**和访问地址绑定**。请固定用 `http://localhost:8080/` 这一个地址，并在「设置 → 导出备份」定期备份。

## 自定义词库

在应用内进入「主题生成」页面：
1. 输入你想要的主题（如"航空发动机"）
2. 复制生成的提示词，粘贴到任意AI聊天工具
3. 把AI返回的结果粘贴回应用
4. 确认导入即可

## 数据存储

所有数据保存在浏览器本地 IndexedDB 中。建议定期在「设置」页面导出备份。
